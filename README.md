# Mobile Displaywala

A doorstep mobile repair landing page inspired by the provided design.

## Run locally

```bash
python app.py
```

Then open:

```bash
http://localhost:5000
```

## GitHub-ready setup

Initialize a repo and push to GitHub:

```bash
git init
git add .
git commit -m "Initial site copy"
git branch -M main
git remote add origin <your-github-repo-url>
git push -u origin main
```
